# SkylanderPortal

What?

A small website (html/javascript) to simulate choosing figures for the Skylanders game series.

Why?
- Have a list of figures and their properties
- Keep track of which figures have died this level

Features
- Choose the game: currently including the first 3 from the Skylanders games
- Select figures for up to 2 players
- Filter figures by type, element or special ability
- Select random from the (filtered) list
- Mark figure as dead
- Reset (revive all figures)
